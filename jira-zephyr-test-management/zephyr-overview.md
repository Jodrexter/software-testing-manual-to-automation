# Zephyr for Jira – Test Management Overview

Zephyr is a test management tool integrated with Jira that helps QA teams manage test cases, execution, and reporting.

## Key Concepts
- Test Case
- Test Cycle
- Test Execution
- Defect Linking
- Traceability

## Usage in Agile Projects
- Test cases are mapped to Jira stories
- Test cycles are created per sprint
- Execution status is tracked in real time
