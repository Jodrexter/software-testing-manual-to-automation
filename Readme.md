📌 Overview

This repository documents my end-to-end QA learning and practice journey, transitioning from Manual Software Testing to Automation Testing using Selenium with Java.
It demonstrates real-world QA workflows, structured test artifacts, and automation scripts aligned with industry testing standards.

The repository is designed to showcase my job readiness for Manual QA / Automation Tester (Entry-Level) roles, highlighting both testing fundamentals and hands-on implementation.

🎯 Learning Objectives

Develop a strong foundation in software testing principles and QA processes

Gain practical, hands-on experience in manual testing across web applications

Transition from manual test execution to Selenium-based automation

Apply industry-standard test documentation practices

Practice version control and structured project organization

Build interview-ready QA knowledge with practical examples
