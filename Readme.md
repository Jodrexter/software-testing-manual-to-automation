📌 Overview

This repository documents my structured learning journey from Manual Software Testing to Automation Testing using Selenium with Java.
It showcases practical QA artifacts such as test cases, defect reports, testing notes, and automation scripts, following real-world industry practices.

The purpose of this repository is to demonstrate my readiness for QA / Manual Tester / Automation Tester (Fresher) roles.

Build strong software testing fundamentals

Transition from manual testing to Selenium automation

Practice clean documentation and version control
